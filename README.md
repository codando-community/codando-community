<h1 align="center">Codando Community</h1>

<p align="center">Landing Page do Codando Community, com integração com o bot Cody e descrição sobre nós</p>

<p align="center">O projeto foi desenvolvido em Html, Css, JavaScript e React. Está hospedado na plataforma brasileira <a href='https://bohr.io/'>Bohr.io</a> </p>

<h2 align="center">Tecnologias</h2>

<li>HTML, CSS e JavaScript</li>
<li>React (JSX) — página FAQ</li>
<li>Vite — bundler do projeto React</li>

<h2 align="center">Páginas</h2>

<li><strong>Quem somos</strong> — apresentação da comunidade, pilares e projetos</li>
<li><strong>FAQ</strong> — perguntas frequentes com busca, acordeão e lightbox</li>
<li><strong>Eventos</strong> — calendário de eventos da comunidade</li>

<h2 align="center">Requisitos para rodar o projeto</h2>

<li>Instalar Visual Studio Code</li>
<li>Instalar Git</li>
<li>Instalar Node.js</li>
<li>Clonar o projeto para a máquina</li>
<li>Rodar <code>npm install</code> na pasta do projeto</li>
<li>Rodar <code>npm run dev</code> para iniciar o servidor local</li>

<h2 align="center">Descrição do Projeto</h2>

<p>O Codando é uma comunidade de TI criada por veteran@s que fazem parte de algum curso de tecnologia.</p>

<p>O projeto tem como intuito disseminar conhecimento de tecnologia, não importa o nível de conhecimento, todos temos algo para contribuir e queremos conhecer o que cada um tem de melhor!</p>
